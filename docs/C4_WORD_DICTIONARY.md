# C4 选词自动翻译与首页词典（2026-11-16）

## 用户操作

- 阅读页长按选中单词或句子，再点击系统选区菜单的“翻译”，弹窗打开后直接加载释义，不再在弹窗里重复点一次翻译。配置未完成或联网失败时显示错误及重试，已有英语发音按钮保留。
- 阅读页仍按所选词在附近段落中的具体含义翻译；不把独立词条的所有意思塞入阅读浮窗。所选文字和附近段落会发送到用户配置的服务，弹窗保留提示。
- 首页查询单个英文单词（支持字母、连字符及英文撇号，最多 64 字符）时使用词典模式；短语、句子和中译英继续使用普通翻译。
- 词典结果按实际词性分组并加粗标题，显示来源音标（如有）、全部去重后的来源词义、中文解释、英文原释义及来源提供的例句。保留选择、复制和来源链接。不会给每个词强行生成名词、动词、形容词、介词等全部栏目。
- 在线首页查询仍先确认地址，并提示单词将交给 Free Dictionary API 查询及由 Qwen 翻译。模拟模式继续明确标记，不能作为真实释义使用。

## 数据来源与模型

使用 [Free Dictionary API](https://dictionaryapi.dev/) 获取真实英文词条。词性、释义条目、例句和音标来自数据源；Qwen-Plus 仅把提供的英文释义翻成中文，不负责自由生成词条或补造词性。

按每批最多 24 个释义、每批约 10000 个英文定义字符生成结构化 JSON，逐条验证输入 ID 与输出 ID 一致、无遗漏或重复，中文非空且包含汉字，再绑定回原词性。最多并行三批以支持多义词；词条查询总预算 55 秒。未收录、来源不可用、结果被截断或映射错误时明确报错，不退化成一条简译冒充词典。

结果标明词条来源、中文由模型翻译、来源 URL 和数据源提供的授权说明。词义覆盖以当前来源实际收录为准，不承诺穷尽所有词典中的全部用法；罕见、过时和专业义也可能被来源收录，需结合语境查看。词典源单次限 512 KB、最多 512 条去重释义，超限明确报错，不静默截断。

服务端内存最多缓存 32 个成功词条、10 分钟，避免反复生成相同公开词义；不在 APP 建查询历史或写入书籍译文。来源或模型错误不会缓存。阅读页语境翻译与首页词典缓存不共用。

## 接口与部署

`TranslationBatchRequest.Purpose` 新增 `DICTIONARY`，旧构造函数仍默认 GENERAL。`LookupQuery` 自动判断英文单词请求；适配器在原 `POST /translate` 中发送 `profile: dictionary`，并要求 `dictionary: true` 响应，旧网关不能静默忽略此能力。词典等待时间 65 秒，其他翻译仍保持原超时。

后端新增 `dictionary_lookup.py`；网关已部署，保留原 Bearer 认证、普通翻译、选词语境及 ASR。词典中文解释默认 `DICTIONARY_MODEL=qwen-plus`，小说和字幕仍使用 `QWEN_MODEL=qwen-mt-plus`，均使用服务器已有百炼凭据；不向 APP 下发厂商密钥。部署模板、Dockerfile 和安装脚本同步更新。Nginx `/translate` 等待时间改为 65 秒；网关及 Nginx 更新前保留 `.before-dictionary-20261116` 备份。

当前用户要求“选词直接翻译”取代旧文档中弹窗再次确认的交互；只保留首次选区操作作为发起动作，以及错误后的手动重试。首页独立查询的在线发送确认仍保留。已有 ViewModel 的单次启动、取消代次、旋转保留和服务快照行为继续有效。
