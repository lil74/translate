# C3 视频连续识别翻译（2026-11-16）

原流程 OCR 完成后停留在未翻译状态，需要再次点击翻译；现改为“识别并翻译画面英文”：选择区域后统一确认，本机 OCR 成功即自动以英文→中文调用已确认的翻译服务，进入现有双语播放、保存和导出流程。

确认时明确说明会替换已有字幕、识别文字将发送到哪个地址，视频不上传；模拟模式明确告知只生成模拟译文。配置无效时在开始 OCR 前提示，避免处理完才发现服务不可用。手动导入字幕及原有继续翻译、重新翻译仍保留。原文可以在流程结束或取消后长按修正。

ViewModel 捕获同一次确认的服务绑定，OCR 后沿用此绑定，配置变化只影响下一次任务；请求代次隔离取消、离开页面、切换视频后的迟到结果，旋转不依赖 Fragment 回调触发翻译。OCR 成功结果保留，即使翻译失败仍可继续翻译。仅修复连续流程，尚未增加 ASR、配音、逐帧时间对齐或 OCR 准确率增强。

新增设备断言：在设备生成带英文的实际视频，OCR 后无需第二次调用翻译，最终全部识别片段均有译文且受控服务收到请求。使用受控服务，不代表用户素材或真实在线质量验收。未修改用户真机项目。

构建、单元测试和 Lint 结果：work/c3-build.log；视频设备回归：work/c3-device-results.log。本轮代码在 C3，尚未提交或推送。
