# 视频横屏全屏与窗口内倍速（2026-11-16）

视频窗口右下角新增“全屏”，点击请求横屏并把整个播放器、字幕与控制按钮移到覆盖页面的全屏容器，隐藏系统栏；点击“退出”或按返回键退出全屏，再按返回才离开视频页面。退出恢复系统默认方向。播放器保持视频原始比例，不强制拉伸或裁掉画面。

倍速选择移入视频窗口右下角，与全屏按钮相邻，支持 0.75、1、1.25、1.5、2 倍速；原来页面下方的倍速 Spinner 已移除。字幕与这两个按钮一起进入全屏。播放位置、暂停/播放状态及倍速通过保留的 ViewModel 在方向切换时恢复；识别与翻译任务不会因这次配置切换重新提交。

Debug、测试 APK、Release Java 编译及 68 项单元测试通过；Lint 0 错误、111 警告。Pixel_6 API 34 视频专项 7 项通过、0 跳过、27.13 秒。新增用例验证横屏与容器占满可用屏幕、退出回到竖屏，以及 700ms 播放位置、2 倍速和字幕片段保留。没有调用真实 ASR 或上传用户素材。日志 work/fullscreen-final-build.log、work/fullscreen-device-results.log。
