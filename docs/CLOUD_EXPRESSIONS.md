# 账号云端收藏

## 2026-11-18 ECS 部署记录

云端收藏接口已部署到项目 ECS `8.148.28.233`。部署前账号数据库备份为 `/opt/bilingualreader/backups/accounts.before-expressions-20261118.sqlite`，服务代码与 Nginx 配置备份在同目录，文件名含 `before-expressions-20261118`。线上用两个临时账号验证添加、列表、重复收藏、跨账号拒绝删除与账号内删除，随后清理临时账号；现有云端书库仍返回预期的未登录 401。

登录账号后，在阅读页选中文字并点“收藏”，单词或短语会保存到当前账号的云端收藏。打开“我的 → 我的收藏”可查看该账号的列表；点击词句进入词条详情，长按删除当前账号的云端条目。另一台设备登录同一账号即可读取列表，不同账号互相隔离。

未登录时仍保存到本机。此前版本积累的本机收藏不会自动上传，避免将同一设备上的旧内容错误归给其他账号；登录后，收藏页提供“同步本机收藏到当前账号”按钮，显示账号和条目数并要求确认。云端请求失败时，选中的新内容暂存在本机，之后可手动同步。

服务端使用 `GET /expressions` 列表、`POST /expressions` 添加和 `DELETE /expressions/{sha256}` 删除，均要求账号 Bearer 令牌。账号数据库中的 `expressions` 表以用户 ID 和内容哈希为联合主键。当前每账号最多 500 条，每条最多 400 字符。

验证：`python -m unittest discover -s backend -q` 与 `gradlew.bat :app:assembleDebug`。手机端尚需安装新版 APK 验证交互。
