# 阅读操作栏与本地阅读设置

2026-11-13。阅读沿用上下滚动、段落对齐与长按选词翻译。

## 使用

- 进入正文时左上角显示书名，底部左侧显示当前章节，右侧显示阅读百分比。百分比按全书段落数和当前段落的滚动比例估算，包含前言等内容；不是按显示的章节数字推算。滚动、切换章节、恢复阅读和书签跳转会刷新。正文与信息栏各自占位，文字不会被信息栏盖住。轻点正文中间区域（横向、纵向各 20%–80%）只显示或收起上下操作栏，默认不展开设置、背景或章节面板，拖动正文也会收起；系统返回键优先收起面板，再次返回离开阅读。长按选择文字不切换操作栏。
- 上方左侧为返回和实际内容标题，右侧依次为收藏、书签、翻译图标。收藏可再次点击取消，书架中的已收藏书籍以 ★ 标记。
- 书签按钮打开本书列表：添加当前位置、选择已有书签后跳转或删除。同一段落再次添加会更新位置；位置包含章节、段落和滚动偏移。换书不会混用书签。
- 下方“设置”：字号 14–30 sp、行距 1.2–2.0、页边距 12–44 dp、普通或加粗字重，即时保存。设置面板参考示例采用横向滑杆排版，小屏幕可以滚动。
- “背景”：日间、夜间方案，亮度 5%–100% 或跟随系统。拖动亮度滑杆会退出跟随系统；离开阅读恢复窗口默认亮度，不要求修改系统设置的权限。
- “切换章节”：上一章、当前真实标题、下一章；边界按钮禁用。“目录”沿用简洁目录和段落锚点。
- 翻译图标仍在顶部右侧，点开后使用原有整章翻译菜单；长按选词的浮窗仍可独立使用。

## 文件与协作边界

| 文件 | 用途 |
| --- | --- |
| `ui/reader/ReaderControls.java` | 阅读操作栏、底部面板、收藏和书签操作 |
| `ui/reader/ReaderLocalStore.java` | SharedPreferences 收藏、书签及新增排版和亮度设置 |
| `ui/reader/ReaderFragment.java` | 轻点与滚动手势、窗口亮度、阅读位置及控制器接线 |
| `ui/reader/ParagraphAdapter.java` | 原文加粗，保留选词翻译 |
| `viewmodel/ReaderViewModel.java` | 按章节、段落、偏移跳转书签，清除旧视口恢复 |
| `res/layout/fragment_reader.xml` | 覆盖在正文之上的操作栏和设置区域，不改变正文视口大小 |

字体、行距、日夜主题仍使用既有 SettingsRepository；新增数据存在应用私有的 `reader_controls` preferences，收藏和书签使用 bookId 分组，不修改 B/C 的数据库和翻译接口。卸载或清除应用数据会清除这些设置和标记。当前书签以段落为单位，不是某个单词或某一行。

## 手工验收

1. 进入正文不显示操作栏；中间单击显示，再次单击或滚动收起。长按原文仍能选择并翻译，拖动选择柄不会唤起设置。
2. 调整四个排版滑杆，重新进入仍保留设置；切换日夜后检查正文、操作栏和浮窗颜色。
3. 调整亮度检查实际亮度变化，启用跟随系统；退出阅读检查亮度恢复。
4. 收藏本书，返回书架检查星标，再进入取消收藏。
5. 在一章中间添加书签，换章或重启后从书签跳回；检查位置、删除和重复添加。另一书的列表应独立。
6. 检查首尾章节按钮、目录锚点、翻译菜单，以及横屏或大字号下设置面板的滚动。
