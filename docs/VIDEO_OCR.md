# 视频画面英文识别（2026-11-15）

只需导入视频，点击“识别画面英文（无需字幕文件）”，选择底部 35%、中下部 60% 或整个画面。识别结果进入现有字幕列表，可以长按修正原文，然后点击翻译；在线翻译仍需确认发送字幕文本，原视频不上传。可继续双语播放和字幕导出。

使用内置 ML Kit 拉丁文字模型在本机识别，不依赖手机 Google Play 在线下载模型。初版限制视频不超过 10 分钟，每 500 毫秒抽取实际帧；仅保留包含英文字母的识别文本，连续完全相同的结果合并成同一个 OCR 片段。时间轴为采样近似值，并非逐帧精准对齐；短暂文字可能遗漏，识别抖动可能生成碎片。全画面识别也可能包括水印、标题，应选尽量窄的字幕区域，并核对原文。没有实现手绘框选和 ASR。

OCR 在前台后台线程执行，显示百分比；取消、离开页面隔离迟到结果，旋转不重复启动。识别失败或取消保留原项目；成功后替换原字幕和译文，开始前有明确提示。视频文件解码及清晰度受设备限制。

新增 `video/VideoOcr.java`、`VideoViewModel.recognize` 和页面识别入口。复用统一的 OCR 来源字幕片段、翻译服务、项目存储和字幕导出，无须修改云端接口。

构建、原单元测试、Lint 通过。Pixel_6 API 34 模拟器视频专项 5 项通过，0 跳过，26.481 秒；新增用例把英文绘入 MediaCodec 编码视频，实际抽帧 OCR 识别 Hello world。受控测试不代表对用户真实视频质量的验收。日志位于忽略的 work/video-ocr-*.log。
