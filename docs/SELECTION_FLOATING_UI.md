# 选词 / 选句翻译浮窗调整

选词翻译由固定占屏 70% 的底部面板改为应用内浮窗。

- 窗口优先放在所选文字上方；空间不足时放在下方，尽量避开所选原文。短内容自然收缩，不保留底部大块空白。
- 清除背景变暗效果；原文保持原来的日间/夜间配色。
- 窗外触摸可交给阅读页，便于继续滑动、对照原文。
- 拖动标题栏可移动浮窗，右上角 × 关闭，返回键也可关闭。
- 长译文在窗内滚动，滚动内容区域最多占屏幕高度 30%；所选原文最多展示三行。
- 重新选择文字时替换旧浮窗；切换到其他章节时关闭旧查询窗，避免与原文上下文混淆。

仅使用应用内 Dialog 窗口，不需要系统悬浮窗权限。临时翻译的接口、发送确认、加载、重试、取消与迟到响应隔离保持原约定。

## 实现位置

- `SelectionTranslationSheet.java` 保留原类名和标签以兼容阅读页接线，基类改为 AppCompatDialogFragment；窗口不再使用 BottomSheetBehavior。
- `sheet_selection_translation.xml` 改为紧凑标题栏 + 有高度上限的滚动正文。
- `SelectionResultScrollView.java` 控制长结果的最大显示高度。
- `selection_floating_theme.xml` 和 `selection_floating_background.xml` 提供无暗色遮罩的圆角浮窗。

设备测试已增加无 dim flag、dimAmount=0、窗外触摸可用标记、按内容高度和顶部位置断言；这些断言是否实际通过，以本轮验证记录为准。
