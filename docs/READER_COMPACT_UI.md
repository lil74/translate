# 阅读页精简调整

## 使用方式

- 顶部工具栏左侧显示书籍自身的章节/内容标题，替代原先独立的章节标题区域。明确的数字章节标题显示为“第 N 章”；前言、目录等不计入正文章节编号。
- 三个点菜单左侧是翻译图标；点击后显示当前翻译进度，以及翻译本章 / 继续 / 重试 / 取消等适用操作。
- 阅读区上方仅保留“长按原文选择单词或句子，再点击翻译”的提示；常驻状态文字和进度条不再占用正文空间。
- 段落未翻译时只有原文，不展示空译文框。任务正在处理或存在成功/失败结果时，按状态显示译文或提示。
- 取消后保留成功结果，尚未处理的段落不显示空框。原生选词与底部临时翻译弹窗保持原有入口。

正文中的章节标题属于 EPUB 原文，仍正常显示和滚动。工具栏优先使用对应阅读资源的目录标题，没有合适目录项时使用 Chapter 已保存的正文标题；不会将 spine 顺序加一当作章节号。段内锚点标题不冒充整个资源的标题。

## 代码位置

- `ui/reader/ReaderFragment.java`：生命周期内工具栏菜单、章节序号、按需翻译操作与状态。
- `res/layout/fragment_reader.xml`：删除独立章节/状态/翻译按钮区域。
- `ui/reader/ParagraphAdapter.java`：无译文时隐藏整个译文 TextView，回收复用时清理显示状态。
- `res/drawable/ic_translate.xml`：简易翻译图标。

未修改翻译服务、数据存储、接口字段或 C 的接入方式。

手动检查：

1. 打开未翻译章节，顶部只显示内容标题、翻译图标和三个点；正文上方只有选词提示。
2. 未翻译段落只显示原文，滚动后复用的条目也不出现空译文框。
3. 点击翻译图标，弹出文字操作与当前状态；开始后出现处理提示与逐段译文。
4. 再点图标查看进度或取消；失败后同一菜单提供重试。
5. 切换章节、返回设置页或旋转屏幕，核对章节号与工具栏菜单；选词底部弹窗按原方式使用。

## 章节标题修复补充

原实现直接显示 orderIndex + 1，会把推荐页、引言、目录等前置内容算入正文章节号。现在使用独立的 ReaderSectionTitle 解析显示标签：如 CONTENTS 显示“目录”，Introduction 显示“引言”，实际标题 1 / Chapter 1 显示“第 1 章”，PRAISE FOR THE DEAL 保留原题。

解析只作用于阅读界面，无需重新导入，不迁移数据库，不修改阅读顺序、段落 ID、译文或已保存的位置。缺少可用标题时显示“阅读内容”，不凭文件位置推算章节号。

`tools/java/ReaderSectionTitleCheck.java` 覆盖 23 个回归场景，包括第一章位于第 4/101 个阅读资源、前置内容、目录映射、内部锚点、缺失目录与原题保留。

验证结果：23 项标题解析检查通过，Debug、设备测试 APK、Release 与 Lint 编译检查通过。本次未启动模拟器重跑设备流程；先前的设备截图不代表本次标题修复效果。
