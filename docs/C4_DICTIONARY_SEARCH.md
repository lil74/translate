# 单词联想与详情页

本轮按新的交互要求，首页输入字母后展示前缀匹配的候选词及中文摘要；点击候选词进入独立的“单词详情”页，返回后保留搜索输入。搜索按钮、键盘搜索也可直接打开当前英文单词的详情。短语、句子和中文输入仍可点击搜索直接翻译，取消了每次查询前的确认弹窗。

## 词典来源与行为

- 使用 ECDICT 开源词库（https://github.com/skywind3000/ECDICT，MIT），内置 757442 条带中文释义的英文单词及短语。许可证随资产保留；下载文件 SHA-256 记录在资产 `source.json`。
- 不依赖服务令牌、网络或模拟翻译开关即可检索本地词典。数据是静态词典释义，不是模型模拟结果。阅读页按段落解释选词和视频翻译仍使用原来的配置服务。
- 候选词按前缀查询，完整匹配优先，随后按来源词频排列，最多 40 条。180ms 输入延迟，旧查询回调不能覆盖新输入。当前不提供拼写纠错或任意子串搜索。
- 本地数据库在后台首次解压至应用私有目录，原始约 46MB，压缩资产约 20MB；搜索走 SQLite 主键范围查询，不在 UI 线程扫描词库。
- 详情页包含单词、来源音标、来源考试标签、按来源词性排列的中文释义、朗读按钮及来源链接。不展示英文释义正文，不补造词性、考试标签或例句；本词库多数词条无例句。朗读复用手机英语 TTS，缺少英语语音时提示安装。
- 未收录词条自动使用已配置的在线词典服务。兼容旧后端：客户端过滤“英文释义：”行，保留中文释义和来源例句。在线结果仍遵守原来的模拟/真实标识、超时、取消及失败重试规则。
- 不保存搜索历史；词库文件是公共静态资源，和用户查询、书籍译文缓存分离。没有改动服务器协议或部署。

## 可复现构建

下载上游 `ecdict.csv` 后执行 `python tools/build_dictionary.py work/ecdict.csv`。脚本仅保留中文释义、音标、标签和词频，按小写单词去重，并生成压缩 SQLite 与源文件校验信息。

## 验收
