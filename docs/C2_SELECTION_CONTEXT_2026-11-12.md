## 阅读交互

- 长按原文后点击翻译，使用文字布局的实际选区路径计算屏幕矩形，包含准确横向范围。
- 结果窗口贴近所选文字，优先在上方，空间不足时选择下方/侧边并限制在阅读区内；可拖动标题区域，不使背景变暗，窗口外仍可操作阅读页。
- 修复窗口布局更新期间坐标原点反复校准造成的偏移；译文高度变化后重新贴近选区。
- 所选词、扬声器和关闭按钮处于同一紧凑头部；长结果在窗口内滚动，翻译/重试按钮保留在固定底部，不会被滚动区域截掉。
- 扬声器朗读所选英文，播放时变为停止按钮；关闭、切换窗口或离开前台即停止。初始化、资源缺失与错误均有状态反馈。

发音使用系统 TextToSpeech，优先选择已有离线英语语音；是否联网由实际语音引擎和语音资源决定。没有英语资源时提供安装入口，未找到入口时提示系统设置。不是录制真人音频，也未给出音标或多种口音承诺。

## 语境协议

`TranslationInput` 保留原三参数构造，增加可选 `Context`；整章任务仍使用原请求。临时选词请求保持独立 UUID、所选原文 SHA-256，不写章节译文表。

创建浮窗时从当前段落保存有界语境和所选位置。优先保留选区附近内容，最多 4000 个 Unicode 码点，选区不截断，也不切开 emoji 代理对。位置统一以 Unicode 码点计数，避免 Java UTF-16 与 Python 字符索引错位。同一段里重复出现的相同单词可区分具体哪一次。

网关 `/translate` 增加可选字段：

```json
{"q":"bank","source":"en","target":"zh","format":"text","context":{"text":"She sat on the bank.","start":15,"end":19}}
```

服务器在调用供应商前检查语境大小、范围和选中文字的一致性；使用 Qwen-MT 的领域提示传入前文、当前词和后文，要求只返回该处的简体中文含义，避免整段翻译或无关义项。段落作为数据处理，不能改变接口配置或系统角色。

响应包含 `contextual=true`；Android 收到缺失/否定的能力确认时明确提示服务不支持语境，不会将忽略上下文的普通翻译标为语境释义。原无语境请求继续兼容旧服务。

语境文本只在用户点击翻译后发送，弹窗明确提示将发送所选文字及附近段落。供应商 Key、服务令牌、数据库结构与章节翻译调用方式保持原有边界。
