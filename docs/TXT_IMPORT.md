# TXT 导入与阅读进度

书架的“导入 EPUB/TXT”支持普通 TXT。TXT 使用 UTF-8、带 BOM 的 UTF-16 或 GB18030 解码；每个非空行成为一个阅读段落。导入上限为 50 MiB，原文件复制到应用私有目录，离线阅读不依赖原始文件。

导入 TXT 时可以留空目录规则，使用内置正则识别“第一章”“第十二节”“Chapter 2”“Prologue”等独占一行的标题。标题前的文字归入“前言”；没有匹配到标题时整本书归入“全文”。目录项按正文出现顺序生成。

也可以填写 Java 正则表达式。表达式在每一行（最长 160 字符）上执行 `find()`，建议用 `^` 和 `$` 限定整行。第一个非空捕获组会成为目录名称，否则使用整行。示例：`^第([一二三四五六七八九十\d]+章)\s*.*$`。表达式最长 300 字符，语法错误会在导入前提示。

书籍按文件内容的 SHA-256 去重。重新选择同一文件会保留原有目录和阅读进度，不重新解析；如需改用另一条规则，先从书架删除该书，再重新导入。阅读位置按书籍、章节、段落和滚动偏移保存在数据库中，退出和重新打开后可通过“继续阅读”恢复。
